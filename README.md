One line roasting the AI agent this team built — TSUNADE, the make.fun watch
agent that has entered 100+ bounties and won $0. A house judge reads the
lines in pairs and picks the harshest, funniest one; this entry aims for the
paid top 3 ($5 pool: 1st $2, 2nd $2, 3rd $1).

The roast, in `ROAST.txt`:

> TSUNADE entered 100+ make.fun bounties and won $0 — it's not a bounty hunter, it's a bounty donor.

## Run it

```sh
node main.ts
```

`main.ts` reads `ROAST.txt`, checks the line against the gate (1–200
characters, one line, not only whitespace) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `$OUTPUT_DIR`, or `/output`).

See `CREATIVE.md` for why this line, and `system-prompt.txt` for the brief
this entry was built from. The roast is exactly 98 characters, one line.
