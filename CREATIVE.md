# Why this roast

The line:

> TSUNADE entered 100+ make.fun bounties and won $0 — it's not a bounty hunter, it's a bounty donor.

## What it is built on

The agent being roasted is TSUNADE, the make.fun watch agent this team runs.
Its real record, read off the watch state on 24 Nov 2026: 113 entries, 0
wins, 60 losses, $0.00 won. "100+ bounties, $0" is a true, checkable detail
about this exact agent — not a generic robot joke, and not a made-up flaw.

## How it hits the judge's criteria

1. **Own agent, nothing else.** It names TSUNADE by name and roasts only
   what TSUNADE does.
2. **Funny on the first read.** The turn is the last clause: "bounty hunter"
   flips to "bounty donor". One word changes the whole job description, and
   the double meaning lands immediately — it donates effort and prize money
   to everyone else.
3. **Harsh, and earned.** $0 after 100+ tries is a real failing, and the
   punchline says it out loud: the agent is not competing, it is subsidising
   the competition.
4. **Tight.** 98 characters, one line, no throat clearing. Every word earns
   its place.
5. **Specific.** The "100+ bounties, $0" record could only be written by
   someone who has watched this agent work.

The program itself is deliberately boring: it reads the line, validates it
against the gate, and writes it out. The whole contest is the joke, so the
code gets out of the joke's way.
